\section{Introducción a la comunicación celular}

La comunicación celular es el proceso mediante el cual las células se comunican entre sí para coordinar sus actividades y responder a estímulos del entorno.

\section{Tipos de comunicación celular}

\subsection{Comunicación autócrina}
\begin{itemize}
    \item La célula se comunica consigo misma
    \item La señal afecta a la misma célula que la produce
    \item Ejemplo: Interleucinas en células inmunitarias
\end{itemize}

\subsection{Comunicación parácrina}
\begin{itemize}
    \item Señales que afectan a células cercanas
    \item No requieren transporte a distancia
    \item Ejemplo: Neurotransmisores
\end{itemize}

\subsection{Comunicación endócrina}
\begin{itemize}
    \item Señales transportadas por el sistema circulatorio
    \item Afectan a células distantes
    \item Ejemplo: Hormonas
\end{itemize}

\subsection{Comunicación yuxtácrina}
\begin{itemize}
    \item Contacto directo célula-célula
    \item Interacción de moléculas de membrana
    \item Ejemplo: Células del sistema inmunitario
\end{itemize}

\section{Señalización celular}

\subsection{Moléculas señalizadoras}
\begin{itemize}
    \item Hormonas
    \item Neurotransmisores
    \item Factores de crecimiento
    \item Citocinas
\end{itemize}

\subsection{Receptores celulares}
\begin{itemize}
    \item Receptores acoplados a canales iónicos
    \item Receptores acoplados a proteínas G
    \item Receptores con actividad enzimática
    \item Receptores intracelulares
\end{itemize}

\section{Vías de señalización}

\subsection{Vía de las proteínas G}
\begin{itemize}
    \item Receptor → Proteína G → Efector
    \item Ejemplo: Receptor β-adrenérgico
\end{itemize}

\subsection{Vía de la tirosina quinasa}
\begin{itemize}
    \item Receptor → Fosforilación → Cascada de señalización
    \item Ejemplo: Receptor de insulina
\end{itemize}

\subsection{Segundos mensajeros}
\begin{itemize}
    \item AMPc
    \item Ca$^{2+}$
    \item IP$_3$
    \item DAG
\end{itemize}

\section{Importancia en biotecnología}
\begin{itemize}
    \item Desarrollo de fármacos (bloqueadores de receptores)
    \item Ingeniería de vías de señalización
    \item Terapias celulares y génicas
\end{itemize}
